# ADR-008 · Plano é intenção; habilitação é fato

**Status:** aceita

## Contexto
Seria tentador marcar o substituto como apto quando o plano "Habilitar substituto" fosse concluído.

## Decisão
Concluir o plano não altera a cobertura. O risco só cai quando alguém registra a habilitação com evidência. O plano guarda o score inicial para medir a redução depois.

## Consequências
Sem atalho para "melhorar o número". Na demonstração, o score dos processos com plano aparece igual (36 → 36) até haver habilitação registrada.

## Alternativas consideradas
Criar habilitação automática na conclusão (rejeitado: fabricaria evidência).
