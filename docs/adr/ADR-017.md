# ADR-017 · Release publicada não é implantação

**Status:** aceita

## Contexto
Uma tag no GitHub não prova que aquela versão está na org.

## Decisão
`RAIZ_Implantacao__c` só nasce do relatório real de deploy (`sf project deploy report`); validações (dry-run) são descartadas. Uma release só aparece como implantada quando há implantação com sucesso ligada a ela.

## Consequências
Rastreabilidade versão → deploy → testes → org. Custo: a ligação release ↔ deploy é um passo explícito.

## Alternativas consideradas
Marcar a release como implantada ao publicá-la.
