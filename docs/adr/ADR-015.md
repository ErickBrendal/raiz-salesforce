# ADR-015 · Declarado × verificado: só o verificador valida

**Status:** aceita

## Contexto
Status report de projeto costuma repetir o que alguém declarou.

## Decisão
`Estado_Validacao__c` em `RAIZ_Engineering_Status__c` é somente leitura para todos os permission sets; só `RaizEngineeringVerifier` grava, a partir de Schema, ApexClass, ApexTrigger, FlowDefinitionView, CronTrigger, TabDefinition, AppMenuItem, NamedCredential e ApexTestResult. LWC e cobertura vêm do sf CLI (Tooling API) e valem 7 dias.

## Consequências
Preencher um item não o valida; evidência fica guardada em `RAIZ_Evidencia__c` com origem e data.

## Alternativas consideradas
Campo editável de status (rejeitado: vira autodeclaração).
