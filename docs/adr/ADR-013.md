# ADR-013 · Idempotência por chave no log e por tarefa aberta

**Status:** aceita

## Contexto
Rodar a automação de novo (retentativa, reprocessamento, script) não pode criar tarefa, notificação ou log duplicado.

## Decisão
`RaizLog` grava `RAIZ_Log_Execucao__c` com `Chave__c` única: mesma chave atualiza o registro e soma `Execucoes__c`. Tarefa de revisão só é criada se não houver outra aberta para o documento; notificação só na primeira vez.

## Consequências
A coluna Execuções vira prova visível de idempotência. Custo: a chave precisa ser bem escolhida por tipo de evento.

## Alternativas consideradas
Flags espalhadas em vários campos do documento.
