# ADR-011 · Cadastro guiado em LWC, não em Screen Flow

**Status:** aceita

## Contexto
O cadastro precisa de campos de texto formatado, de voltar entre etapas sem perder dado e de uma tela de revisão com atalhos para corrigir.

## Decisão
LWC `raizGuidedJourney` com regras no Apex (`RaizJourneyService`). A tela pergunta ao Apex o que está bloqueado em cada etapa; não repete regra no JavaScript.

## Consequências
Editor de texto formatado nativo (`lightning-input-rich-text`), testes Jest, controle total da navegação. Custo: mais código que um Screen Flow.

## Alternativas consideradas
Screen Flow (descartado: sem entrada de texto formatado nativa; 7 telas com voltar e revisão em XML ficam frágeis).
