# ADR-016 · GitHub somente leitura, sem segredo, lido da Salesforce

**Status:** aceita

## Contexto
O repositório é público; a leitura anônima do GitHub tem limite baixo por IP e a Salesforce compartilha IPs de saída.

## Decisão
Named Credential `RAIZ_GitHub` sem autenticação; `RaizGitHubService` faz GET de repositório e releases, com timeout de 10 s e tratamento de 401/403/404/429/5xx; resultado gravado em `RAIZ_Release__c`; a tela lê os registros, não o GitHub.

## Consequências
Funciona com o GitHub fora do ar; nenhum segredo no código ou em campo. Para subir o limite: External Credential com token somente leitura, digitado no Setup.

## Alternativas consideradas
Callout a cada abertura de tela (estoura o limite e fica lento).
